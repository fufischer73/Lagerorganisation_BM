Wie arbeitet die chaotische Lagerhaltung?

  1. Ware kommt auf feste Plätze, die nie wechseln
  2. Ware wird dort eingelagert, wo gerade ein Platz frei ist, und das System merkt sich den Ort
  3. Ware wird ohne Plan überall abgestellt

  2. Das Zusammenstellen der bestellten Ware zu einer Lieferung
  3. Das Verpacken von Gefahrstoffen

Wann darf eine Kommission das Lager verlassen?
